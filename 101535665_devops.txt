COMP3104 DevOps Course

COMP3104 introduces students to DevOps concepts and practices used in software development. The course covers topics such as version control, Git, GitHub, continuous integration, and continuous deployment.

In this course, students learn how developers can collaborate using repositories, branches, commits, and pull requests. These tools help teams manage changes to a project while keeping their work organized.

Continuous integration helps developers regularly combine and test their changes. CI/CD can automate parts of the development process and helps teams identify problems earlier.

Learning GitHub Actions also provides experience with automated workflows. These skills are useful when working on software projects with multiple developers.

Git and GitHub are important tools used throughout COMP3104. Git provides version control for tracking changes, while GitHub allows developers to store repositories remotely and collaborate with other team members.

Branching allows each developer to work independently without immediately changing the main branch. Changes can later be reviewed through a pull request before they are merged into the main project.
